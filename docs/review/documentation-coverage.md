## Undocumented and incompletely documented behaviour

Most features have at least a label, tooltip or release-note entry; it would be inaccurate to label those wholly undocumented. The significant missing operating details are: campaign-history retention, clearing limitations and local-only scope; history versus logging switches; global switch restoration; O-number lookup rules; export-only reminder backup; timesheet timezone and DST behaviour; local stats metric definitions; clipboard failures; incomplete Help Guide targets; loading-fact rating workflow; and mailto feedback handoff. The Auto Copy Campaign URL tooltip contradicts the code and README.

README omissions include Help Guides usage, bulk Actualise export, DST Assurance, Actualise month assurance, product-code warnings, direct Moe, Order Summary alignment, restore-after-account-switch, onboarding replay, and the current legacy Billing Check flow. Several are described in release notes or Settings, as shown above.
